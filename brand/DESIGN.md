# 栖聊专属 Logo · 双鸟栖谈

两只面对面的小鸟代表两个具有不同性格的 agent。鸟的轮廓也像对话气泡，连接它们的弧线同时像栖枝、巢和微笑。两侧的叶片表达生长与陪伴。

主色 `#7662CD` 沿用产品界面的紫色，副色 `#BBA8ED` 区分另一位交流者，薄荷绿 `#8FBBA2` 为辅助色。应用图标底色为 `#F1EDFA`。

## 文件

- `public/brand/logo.svg`：透明、可缩放的图形标志。
- `public/brand/logo.png`：1024 × 1024 的透明 PNG。
- `public/brand/wordmark.svg` / `.png`：图形 + 栖聊 + AGENT LOUNGE 横版组合。
- `public/brand/app-icon.svg` / `.png`：适配侧栏及桌面的淡紫圆角图标。
- `lounge-brand-v1.ico`：Windows 图标，包含 16 / 24 / 32 / 48 / 64 / 128 / 256 像素。
- `brand/concept.png`：ImageGen 生成的图形探索稿。最终生产版本依据探索稿用原生 SVG 整理，去除了渐变与边缘杂色。

避免拉伸、旋转或在鸟之间增加文字；保留周围留白。细小尺寸优先使用应用图标，不要使用含文字的横版组合。
